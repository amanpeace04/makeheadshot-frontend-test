# MakeHeadShot Frontend

This is the frontend for the **MakeHeadShot** web application — a smart AI-powered platform to generate professional headshots. It connects with a backend and uses services like AWS S3, Razorpay, and Replicate for image generation.

---

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/makeheadshot-frontend.git
cd makeheadshot-frontend
```

---

### 2️⃣ Install Dependencies

```bash
npm install
```

---

### 3️⃣ Configure Environment Variables

Create a `.env.local` file in the root of the project and add:

```env
NEXT_PUBLIC_APP_API_URL=https://your-backend-url.com
NEXT_PUBLIC_RAZORPAY_KEY=your-razorpay-key
NEXT_PUBLIC_API_KEY=your-api-key
```

> Replace the values with your actual env values.

---

### 4️⃣ Run the Development Server

```bash
npm run dev
```

The app will be running at: [http://localhost:3000](http://localhost:3000)
